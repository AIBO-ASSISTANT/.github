# Runbook Placeholder

This file defines the minimum runbook format. It is not a claim that production runbooks exist.

## Required Runbook Fields

- service
- owner
- environment
- health check URL or command
- dashboards
- logs
- common failure modes
- safe restart procedure
- rollback procedure
- dependency checks
- escalation path

Use [../templates/runbook-template.md](../templates/runbook-template.md) when creating service runbooks.
