# Frontend Setup

From `AIBO-FRONTEND`:

```bash
npm install
npm run dev
```

## Useful Commands

```bash
npm run lint
npm test
npm run build
npm run format:check
```

## Current UI Scope

Implemented or partial:

- app routing
- protected dashboard route
- login/signup pages
- auth context and browser session restore helpers
- shared API client

Planned or incomplete:

- complete task UI
- complete schedule UI
- complete project board UI
- chatbot interface
- dashboard insights
