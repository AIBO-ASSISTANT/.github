# Workflow Expectations

## Before You Start

- Read the issue or task.
- Identify affected repositories.
- Check current maturity status.
- Confirm whether docs or ADRs are required.

## While Working

- Keep changes scoped.
- Follow local repository patterns.
- Add tests proportional to risk.
- Keep docs synchronized.
- Communicate blockers early.

## Before Opening a PR

- Run relevant checks.
- Update API docs if contract changed.
- Update architecture docs if boundaries changed.
- Update maturity matrix if capability status changed.
- Use the pull request template fully.

## Review Culture

Reviews are part of delivery. Feedback should be specific, and responses should resolve the technical concern rather than defend the original approach by default.
