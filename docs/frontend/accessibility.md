# Frontend Accessibility

## Baseline

- Forms must have labels associated with inputs.
- Buttons must be buttons, not clickable divs.
- Keyboard users must be able to complete core workflows.
- Focus states must remain visible.
- Color must not be the only signal.
- Error text must be programmatically associated where practical.
- Interactive controls must have accessible names.

## Review Checklist

- Can the workflow be completed with keyboard only?
- Is focus order logical?
- Are errors understandable without visual-only context?
- Are loading and disabled states announced or clear?
- Do screenshots show text truncation or overlap?

## Current Status

Accessibility is a standard, not yet a verified compliance claim. Add audits and automated checks before claiming a formal accessibility level.
