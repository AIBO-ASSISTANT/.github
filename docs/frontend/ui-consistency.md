# Frontend UI Consistency

## Rules

- Use one visual system per product area.
- Reuse route layouts and form patterns.
- Keep action labels specific.
- Show validation errors near the relevant field.
- Preserve keyboard navigation.
- Do not expose raw backend error internals to users.
- Keep loading, empty, and failure states designed, not accidental.

## Product Workflow Expectations

Core user workflows should eventually include:

- auth entry and session restore
- dashboard overview
- task list and task detail behavior
- schedule day/week behavior
- project board behavior
- intent/chat capture behavior with confirmation

Until these are implemented, documentation must describe them as planned or partial.
