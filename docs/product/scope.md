# Product Scope

## In Scope for Current MVP Direction

- User authentication and session lifecycle.
- Personal task management.
- Daily schedule management.
- Project and project task management.
- Intent classification for supported productivity commands.
- Manual user review and editing of structured data.
- Basic dashboard entry point.

## Out of Scope Until Explicitly Approved

- Autonomous execution without confirmation.
- Paid SaaS billing.
- Mobile applications.
- Real-time collaboration.
- External calendar write integration.
- OpenAI/LLM provider integration.
- Predictive analytics.
- Production SLO commitments.

## Why This Boundary Exists

The backend and engine have useful foundations, but frontend workflows, deployment, CI/CD, observability, and AI evaluation are not mature enough to support broad product promises. The MVP must first make implemented workflows reliable and observable.
