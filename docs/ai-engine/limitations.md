# AI Limitations

The current engine is deterministic and limited by explicit rules.

## Current Limitations

- No OpenAI or hosted LLM provider is implemented.
- No model training or embedding retrieval exists.
- Natural language coverage is narrow.
- Relative date handling depends on caller-provided context.
- Entity extraction can miss or misread complex phrasing.
- Confidence is rule-derived, not statistically calibrated.
- Backend currently consumes the simple classification transport, not the full action pipeline.

## Documentation Rule

Do not describe AIBO as having advanced AI planning, autonomous recommendations, predictive scheduling, or LLM understanding until those capabilities are implemented and evaluated.
